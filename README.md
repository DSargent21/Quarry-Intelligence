## 🛰 SYSTEMS OVERVIEW

### V9 CITRINE // THE FORWARD DOOR
*Series IX — higher volume, same honesty.* A skill-gated blend of the shrunk capper-skill
model and the point-in-time ML ranker, capped at 8 picks a day.
*   **Protocol**: walk-forward with monthly retrains, 3-day result lag, pre-fold calibration,
    day-clustered bootstrap intervals; policy frozen before the out-of-sample window.
*   **Out-of-sample (Apr–Sep 2026)**: n=1,126, WR 56.0%, ROI +6.21%, adj **+5.92%**,
    t=+2.21, 90% CI [+1.5%, +10.4%], +70.0u.
*   **Volume**: cap 5/day scores +8.1% but is too thin to judge; 20/day collapses to +2.0%.
    8/day is the frozen sweet spot.
*   **Live tracking**: [Citrine Tracker](https://dsargent21.github.io/Quarry-Intelligence/web/citrine.html)
    — forward-first; the ledger starts at zero and only forward picks decide whether it earns trust.
*   **Read**: [SERIES 9: CITRINE Audit](docs/reports/CITRINE_REPORT.md)

### V8 JADE // THE QUARRY LEDGER
*Score-optimized selection.* Built to maximise the CappersTracked grade itself: Bayesian-shrunk,
odds-clamped scoring implemented byte-exact, ranked daily slates capped at 5 bets, flat 1u.
*   **Protocol**: anchored walk-forward with monthly retrains, fully causal early stopping and
    calibration; one pre-registered policy round, evaluated once on a frozen September 2026 holdout.
*   **Frozen holdout (Sep 2026)**: n=95, WR 58.9%, raw +11.7%, adj +7.7% → grade **A**;
    deployment-realistic under posted-odds-only selection: n=88, adj +8.9%. Single-month
    sample — the forward test decides, and it is currently running negative.
*   **Live tracking**: [The Quarry Ledger](https://dsargent21.github.io/Quarry-Intelligence/ledger/)
    — one frozen slate per day, published automatically at 18:30 Central.
*   **Read**: [SERIES 8: JADE Audit](docs/reports/JADE_REPORT.md)

### V7 RUBY // THE FROZEN POLICY TEST
*The original honest edge.* Policy frozen on a leakage-controlled walk-forward, now live-tested
with no retraining and no re-tuning.
*   **Protocol**: policy grid (216 configs) tuned only on Nov 2025–May 2026 folds; frozen
    Jun–Aug untouched. Acceptance bar: t ≥ 2, n ≥ 80, ≥ 2/3 months positive.
*   **Walk-forward result (frozen)**: n=307, ROI +11.0%, t=+2.04, +33.8u, positive 3/3 months.
*   **Universe**: Discord-sourced picks — every row whose source is *not* one of the four
    tracked public sites (Winners & Whiners, WagerTalk, SportsLine, SportsCapping).
*   **Live tracking**: [Ruby Forward Ledger](https://dsargent21.github.io/Quarry-Intelligence/web/ruby.html)
    — updated daily by the pipeline, graded at posted prices.
*   **Read**: [SERIES 7: RUBY Audit](docs/reports/RUBY_REPORT.md)

## 🔄 AUTOMATION

Two GitHub Actions workflows keep this file, the site and every ledger current. Neither one
retrains a deployed model.

| Workflow | Schedule | What it does |
| --- | --- | --- |
| **Daily Quarry Ledger** | 23:30 UTC | Jade frozen slate → grade → rebuild ledger page → refresh README → commit → Pages |
| **Daily Quarry Pipeline** | 09:00 UTC | data ingest → Ruby frozen tracker → refresh README → commit → Pages |

`scripts/update_readme_metrics.py` rewrites the model-table cells and the live scoreboard
from `docs/ruby_forward.json`, `docs/ledger/ledger_summary.json` and
`docs/web/citrine_summary.json`. It refuses to publish a ledger older than 26 hours for the
workflow that produced it, so a dead pipeline fails loudly instead of freezing numbers.
